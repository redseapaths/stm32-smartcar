## 1. 四条铁律（违反任意一条，轻则调一天，重则烧板）

1. **所有 GND 必须连到同一个点。** 电池负极、LM2596 输出负极、STM32 的 GND、TB6612 的 GND、传感器的 GND、编码器的 GND、USB-TTL 的 GND —— 全部共地。少一根地线 = 信号乱飞。
2. **电机的大电流绝不过面包板、绝不过杜邦线。** 电机线、电池线、VM 线一律用 22AWG 硅胶线 + 接线端子（或鳄鱼夹）。面包板只走"信号"和"3.3V/5V 小电流"。面包板单路大约能扛 1A，电机堵转 2A 会把它烧出坑。
3. **任何模块第一次上电前，先用万用表量电压。** 顺序永远是：**先量，再插。** LM2596 出厂默认不一定是 5V，可能是 12V，直接接 STM32 = 当场烧。
4. **电池正负极绝不能反。** 反接瞬间 LM2596 和 STM32 一起报废。接线端子拧好后，**用万用表蜂鸣档量一遍正负极有没有短路**，再插电池。

**额外一条软规则：** TB6612 每通道标称 1.2A，MG310 堵转 2A。**程序里 PWM 上限锁在 70%**，别写 100%。

## 2. 器件接口一览（先认清每个器件有哪几个口）

### 2.1 STM32F103C8T6 最小系统板（Blue Pill）
- 两侧各 20 个针，丝印就是引脚名：`PA0`–`PA15`、`PB0`–`PB15`、`3.3`、`5V`、`GND`、`VBAT`
- 一端有个 **4 针 SWD 小排针**：`3.3`、`SWDIO(PA13)`、`SWCLK(PA14)`、`GND`
- 自带 AMS1117 稳压：**给 5V 脚供 5V，板子上就能量到 3.3V**（3.3 脚同时也变成 3.3V 输出，可以给别的模块供电）
- ⚠️ 5V 脚和 3.3 脚**不要同时**接两路电源（比如 ST-LINK 供 3.3V + 电池供 5V，等于两个电源打架）

### 2.2 TB6612FNG 双路电机驱动模块
按丝印对照，共 14 个口：

| 口 | 含义 | 接到哪 |
|---|---|---|
| `VM` | **电机电源**（电池 7.4V） | 电池正极（经开关） |
| `VCC` | **逻辑电源**（3.3V） | 面包板 3.3V 轨 |
| `GND` ×2 | 地 | 面包板 GND 轨 |
| `STBY` | 待机脚，**必须拉高**才有输出 | 3.3V |
| `AIN1` `AIN2` | **右**电机方向 | PB12 / PB13 |
| `PWMA` | **右**电机速度（PWM） | PA8（TIM1_CH1） |
| `BIN1` `BIN2` | **左**电机方向 | PB14 / PB15 |
| `PWMB` | **左**电机速度（PWM） | PA11（TIM1_CH4） |
| `AO1` `AO2` | **右**电机输出（接电机） | 右电机 M+ / M− |
| `BO1` `BO2` | **左**电机输出（接电机） | 左电机 M+ / M− |

> ⚠️ **通道和轮子的对应是"反"的**：TB6612 的 A 通道（AO/PWMA/AIN）驱动**右**轮，B 通道驱动**左**轮。这不是笔误 —— 2026-10-30 按车上的实际接线对齐，代码里 `SPEED_R = PWMA`、`SPEED_L = PWMB`。

方向真值表（记下来，调车必用）：
```
AIN1=1 AIN2=0  → 正转
AIN1=0 AIN2=1  → 反转
AIN1=0 AIN2=0  → 停止（惰行，轮子自由滑）
AIN1=1 AIN2=1  → 刹车（短接电机）
```

### 2.3 MG310 减速电机（PH2.0-6P）
**一个插座同时包含"电机"和"编码器"两部分。市面上有两版 6P 定义，针脚顺序是镜像的 —— 必须先确认是哪一版**（2026-10-30 已确认：我们买的是 **GMR 版**）。

| 针脚 | 霍尔编码器版 | **GMR 编码器版（★ 我们买的是这个）** |
|---|---|---|
| 1 | 电机 − | **电机 +** |
| 2 | 编码器 VCC | **编码器 GND** |
| 3 | 编码器 A 相 | **编码器 B 相** |
| 4 | 编码器 B 相 | **编码器 A 相** |
| 5 | 编码器 GND | **编码器 VCC** |
| 6 | 电机 + | **电机 −** |

> 怎么确认：看电机尾部丝印/贴纸，或卖家给的"编码器接线说明"图（两版的 1↔6、2↔5、3↔4 正好互换）。

**不用背版本的两条通用规则：**

1. **找电机线**：万用表通断挡挨个量 6P 各脚 —— 与另外某一脚之间阻值只有几欧、且手转电机时阻值不变的那两根，就是电机线（M+ / M−）；剩下 4 根是编码器。
2. **驱动接法**：`AO1`（AIN1 给高时输出高）接 **M+**，`AO2` 接 **M−**；`BO1`→M+，`BO2`→M−。这样"正转"就是常规方向宏。GMR 版 M+ 在 1 脚，所以 **AO1→1 脚、AO2→6 脚**。

> ⚠️ 编码器**只能用 3.3V 供电**：信号进的是 `PB6`–`PB9`，STM32 的 IO 一律不耐 5V，5V 供电会打坏 IO。

### 2.4 8 路循迹模块（**你们买的是模拟版**，10-30 已确认）
- **模拟版**（你们这个）：`VCC` `GND` `D1`–`D8` + `IR`，红色板 66×16 mm，**背面没有电位器**，`D1`–`D8` 输出**模拟电压**（遮挡时电压下降，变化范围约 1V）
- **数字版**：同样 10 针，但每路带一个蓝色小电位器，输出只有 0V / 3.3V
- → 模拟版**必须进 ADC**：`D1`–`D8` → `PA0`–`PA7`（`ADC1_IN0`–`IN7`），详见第 8 节
- → `IR` 脚：**输入低电平会关掉全部红外管**，悬空可能自激乱跳，直接接 3.3V 保持常开
- → 机械尺寸：**66×16 mm，两个 φ3 固定孔，孔距 36 mm**

### 2.7 面包板
- 每条**横排 5 孔**内部连通，中间凹槽两边**不连通**
- **我们这块的实物结构**（10-30 拍照确认）：上面 5 排 = A–E，下面 5 排 = F–J，中间一条沟槽；上下各 2 条电源轨，**红线条 = +、蓝线条 = −（GND）**
- **没有竖缝**（10-31 用户确认）：红轨、蓝轨都是**整条通的**，从左到右随便挑一个孔插都行；只有"分断上下的横缝"（电源轨与孔区之间、上下两个 5 排区之间）

> **电源轨必须自己跳线连通（10-31 补充）**：面包板上有 **4 条独立金属条**——上红、上蓝、下蓝、下红，彼此都不通。所以：**上蓝 ↔ 下蓝 要跳一根线**（都是 GND，图 4 右侧那根竖线就是它）；**上红(3.3V) 与 下红(5V) 绝对不要连**（一碰就是电源短路）。另外很多面包板的同一条轨**中间是断开的**，插完用万用表通断挡量「同一根蓝轨最左孔 ↔ 最右孔」，不响就得再补一根跳线。
- **Blue Pill / TB6612 不要插在板子正中间**：它们两排针间距约 15 mm（= 6 个孔距），而这块板每半只有 5 排 → 只能**跨着沟槽插**；一旦居中插，两排针之间的那几排孔全被板身自己盖住，插不出线。
  ✅ 正确插法：让两排针落在**靠下**的两排（通常是最下面一排 J + 往上数第 7 排，即 D 排），这样上面 A–C 三排是空的，信号线从那里引。

> **插孔位看图 4**：[图4-面包板插法.png](图/图4-面包板插法.png)。图 4 已按你们这块板重画：上下各 5 排、红=正 蓝=负、中间只有横沟槽、没有竖缝；列号从最左边数孔（1 开始）。
> 两只模块都插在 **上排 B、下排 H**（跨沟槽），这样 A 排和 I、J 排是空的，所有线都插在空排上；表里的孔位就是"列号 + 行字母"。
> 如果插上去发现针脚落在别的排（比如 C + I），**列号一个都不变**，把表里的行字母整体换一下即可（A→B、I→J）。

## 3. 阶段 A：电源系统接线（W01–W10）

> 先做电源，因为后面所有东西都靠它。**这一段做完不接任何板子，只量电压。**

![图 1　电源系统接线：电池→开关→端子→TB6612 VM / LM2596→5V](图/图1-电源系统.png)

| 线号 | 从 | 到 | 线材/颜色 |
|---|---|---|---|
| W01 | 电池组 **红(+)** | 接线端子 1 号位 | 22AWG 红 |
| W02 | 接线端子 1 号位（同组另一孔） | KCD1 开关 **脚 1** | 22AWG 红 |
| W03 | KCD1 开关 **脚 2** | 接线端子 2 号位（= 总正极，记作 `VBAT+`） | 22AWG 红 |
| W04 | `VBAT+` | TB6612 **VM** | 22AWG 红（**先不接，Phase 5 再接**） |
| W05 | `VBAT+` | LM2596 **IN+** | 22AWG 红 |
| W06 | 电池组 **黑(−)** | 接线端子 3 号位（= 总负极，记作 `GND`） | 22AWG 黑 |
| W07 | `GND` | TB6612 **GND**（两个 GND 脚都要接） | 22AWG 黑（**先不接，Phase 5 再接**） |
| W08 | `GND` | LM2596 **IN−** | 22AWG 黑 |
| W09 | LM2596 **OUT+** | 面包板 **红线轨（5V）** | 22AWG 红 |
| W10 | LM2596 **OUT−** | 面包板 **蓝线轨（GND）** | 22AWG 黑 |

**调压步骤（必做，顺序不能变）：**
1. 开关打到 **OFF**，电池**先不接**。
2. 杜邦线/鳄鱼夹把电池正负临时接到 LM2596 的 IN+/IN−（或干脆用可调电源给 7.4V）。
3. 万用表 **直流 20V 档**，红笔 `OUT+`、黑笔 `OUT−`。
4. 用螺丝刀慢慢转蓝色电位器，**调到 5.0V ±0.1V**。
5. 断电 → 再上电 → **再量一次**（有些模块调完断电会漂）。
6. 确认后，才允许接 STM32。

> ⚠️ 千万别做的事：电池直接接 STM32 的 5V 或 3.3V 脚 —— 8.4V 灌进 3.3V 稳压，稳压芯片当场炸。

**✅ 验收 A**：开关 ON → `OUT` 量到 5.0V；开关 OFF → 0V；量 `OUT+` 到 `OUT−` 之间**没有短路**（蜂鸣档不响）。

## 4. 阶段 B：主控上电（W11–W15）

| 线号 | 从 | 到 | 线材/颜色 |
|---|---|---|---|
| W11 | 面包板 **5V 红线轨** | STM32 **`5V`** 脚 | 杜邦 红 |
| W12 | 面包板 **GND 蓝线轨** | STM32 **`GND`** 脚（任选一个） | 杜邦 黑 |
| W13 | STM32 **`3.3`** 脚 | 面包板 **3.3V 轨（贴黄胶带的红线轨）** | 杜邦 黄 |
| W14 | 面包板 **GND 蓝线轨** | 3.3V 轨旁边那条蓝线轨（把两条蓝线轨连起来） | 杜邦 黑 |
| W15 | **预留** | 备用 GND（后面地线不够长时从这里引一根） | 杜邦 黑 |

**上电顺序：** 面包板线全部插好 → 检查杜邦线没有毛刺搭在一起 → 开 KCD1。

> **插孔位请看图 4**：[图4-面包板插法.png](图/图4-面包板插法.png)。这一段对应图 4 的 **7、10、11、14、15 号**线（3.3V → 上轨红、STM32 5V → 下轨红、STM32 GND → 下轨黑、LM2596 两根进轨）。**先只插这 5 根**，量完电压再往下插信号线。

**✅ 验收 B**：
- 板子上电源 LED 亮
- 万用表量 STM32 的 `3.3` 脚 ≈ 3.3V（3.25–3.35）
- 用手摸 AMS1117（板上一小片黑色元件），**温的可以，烫手不行**（烫 = 后面接了太多负载）

> 备用方案：如果量不到 3.3V，说明你的板子 5V 脚没接到稳压输入端（部分克隆板这样）。这时改用：LM2596 输出调到 3.3V → 直接接 `3.3` 脚，**`5V` 脚悬空**。

### 4.3 LM2596 到底在给谁降压（以及装在哪）

**一句话：它只负责把电池 7.4V 变成 5.0V 喂给 STM32 的 `5V` 脚；3.3V 是 STM32 板上的 AMS1117 再降出来的；电机那一路完全不经过它。**

```
2×18650 串（7.4V）
   └─ KCD1 开关 ─ 接线端子 ┬─ 7.4V ──────────→ TB6612 VM   （电机功率，粗线）
                          └─ 7.4V → LM2596 IN+ → OUT+ 5.0V ─┬→ STM32 5V 脚
                                                           │     └─ 板上 AMS1117 → 3.3V ─┬→ 循迹模块 VCC / IR
                                                           │                              ├→ 左/右编码器 VCC
                                                           │                              └→ TB6612 VCC / STBY
                                                           └→ 面包板 5V 轨（备用 5V 取电点，别接循迹）
```

| 电压 | 谁在用 | 大概电流 |
|---|---|---|
| 7.4V（电池直出） | 只有 TB6612 `VM` | 空转 0.2–0.4A，堵转 2A/轮 |
| 5.0V（LM2596 出） | 只有 STM32 的 `5V` 脚 | 30–60mA |
| 3.3V（STM32 板载稳压出） | 8 路循迹 + 2 个编码器 + TB6612 逻辑 | 150–250mA |

- 3.3V 这一路才是电流大头：8 路红外每路 10–20mA，加上编码器霍尔和驱动逻辑，合起来 0.2A 左右。
- 传到 5V 侧 ≈ 0.25A，LM2596 从 7.4V 降到 5V 的损耗 `(7.4−5)×0.25 ≈ 0.6W` —— 模块摸上去温温的，**正常**；发烫到手不敢碰才是问题（通常是后面短路或接了电机）。
- **电机绝不能从 LM2596 取电**：MG310 堵转 2A，模块标称 3A 也扛不住启动冲击，会掉压把 STM32 一起带死（表现为"一开电机单片机就重启"）。这就是为什么 `VM` 必须直接从端子走粗线。

**装在底盘哪里**

1. **位置：电池旁边、靠近车尾**。理由：7.4V 到模块的引线越短越好（这一段是大电流 + 有压降），而且电池和模块一起放在尾部可以当配重。
2. **朝向：蓝色电位器朝上、`IN+/OUT+` 丝印朝上能看清**。调压时要能一边拧一边用万用表量，装死了就得拆。
3. **离底板 5–8mm 架空**：用 M3 尼龙铜柱（你们螺丝包里有）×2 或 ×4，从底板下面穿螺丝上来。模块上没孔的那一端用 3M 泡棉双面胶补一下。
4. **别放在**：驱动轮正上方（溅灰、振动）、STM32 正下方（热往上走）、循迹模块附近（拆装干涉）。
5. **线要防拽**：输入端用端子拧紧后，再用扎带把线固定在底板上做"应力释放"——直接拽线会连焊盘一起扯下来（你们之前就怕粗线掉，这里同理）。
6. **顺手做个标记**：输出那根 5V 线上缠一小段红胶带，将来拆装不会把 7.4V 和 5V 搞混——这两根插反一次就是烧板子。

> 装完、**先不插 STM32**，上电量 `OUT+` 对 `OUT−` 是不是 5.0V（4.95–5.05），再插板子。
>
> **摆位直接看图 5**：[图5-底盘布置.png](图/图5-底盘布置.png)（**已按 10-31 实车 + 仰视图重画**：车头朝下；驱动轮 ×2 与 MG310 在车尾同一根轴上；面包板**横放**在中段，STM32 在左端、TB6612 在右段；电池竖贴车尾右侧、KCD1 在它下面；LM2596 在左侧中部铜柱架空；万向轮在车头方向、循迹探头再往前探出 5–10mm）。

### 电机功率线（这一段要焊/要插紧）

| 线号 | 从 | 到 | 说明 |
|---|---|---|---|
| W34 | TB6612 **`AO1`** | **右**电机 6P **M+（GMR=1 脚 / 霍尔=6 脚）** | 22AWG 红 |
| W35 | TB6612 **`AO2`** | **右**电机 6P **M−（GMR=6 脚 / 霍尔=1 脚）** | 22AWG 黑 |
| W36 | TB6612 **`BO1`** | **左**电机 6P **M+（GMR=1 脚 / 霍尔=6 脚）** | 22AWG 红 |
| W37 | TB6612 **`BO2`** | **左**电机 6P **M−（GMR=6 脚 / 霍尔=1 脚）** | 22AWG 黑 |

> **A 通道（AO）= 右轮，B 通道（BO）= 左轮**（和车上的实际接线一致，别按"AO 就是左"的直觉接）。

> **规则只有一条：`AO1`/`BO1` 接 M+，`AO2`/`BO2` 接 M−。** 我们买的是 GMR 版 → M+ = 1 脚、M− = 6 脚，也就是 **AO1→1 脚、AO2→6 脚**。
> 转向反了怎么办？**先别改线**（拆 6P 插头容易把线拔断），在程序里把 `AIN1/AIN2` 或 `BIN1/BIN2` 对调就行。
> 如果**一定要改线**：AO1↔AO2 对调即可。

### 6.1 免编程验线法（强烈建议先做这个）

在写一行代码之前，先证明"线对了、驱动是好的"：

1. 轮子悬空，电池 ON。
2. 用一根杜邦线把 **`STBY` 直接怼到 3.3V**（如果已经接到 3.3V 就不用）。
3. 用杜邦线把 **`AIN1` 接 3.3V**、`AIN2` 接 GND、**`PWMA` 接 3.3V** → **右**电机应该全速转。
4. 把 `AIN1` 改接 GND、`AIN2` 改接 3.3V → 应该反转。
5. `AIN1` `AIN2` 都接 GND → 轮子应能自由用手转。
6. **左**电机用 `BIN1` `BIN2` `PWMB` 重复一遍（B 通道 = 左轮）。

**这一关过不了，就先别碰代码** —— 是接线/驱动的问题，不是程序的问题。

**✅ 验收 D**：两个电机都能正反转，用手转轮子没有卡死感，TB6612 芯片不烫（温热正常）。

| 线号 | 从 | 到 | 说明 |
|---|---|---|---|
| W38 | 面包板 **3.3V 轨** | 左电机 6P **5 脚（编码器 VCC，GMR 版）** | 霍尔版是 2 脚 |
| W39 | 面包板 **GND 轨** | 左电机 6P **2 脚（编码器 GND，GMR 版）** | 霍尔版是 5 脚 |
| W40 | 左电机 6P **4 脚（A 相，GMR 版）** | STM32 **`PB6`** | TIM4_CH1 硬件编码器 |
| W41 | 左电机 6P **3 脚（B 相，GMR 版）** | STM32 **`PB7`** | TIM4_CH2 硬件编码器 |
| W42 | 面包板 **3.3V 轨** | 右电机 6P **5 脚（编码器 VCC）** | |
| W43 | 面包板 **GND 轨** | 右电机 6P **2 脚（编码器 GND）** | |
| W44 | 右电机 6P **4 脚（A 相）** | STM32 **`PB8`** | EXTI8 软件四倍频（TIM3 被循迹占了） |
| W45 | 右电机 6P **3 脚（B 相）** | STM32 **`PB9`** | EXTI9 软件四倍频（同上） |

> **A/B 相接反只影响计数方向（正/负），不影响能不能用** —— 发现往前走计数在减，软件里取反或把 A/B 对调即可。
> **VCC/GND 接反会烧霍尔/GMR 板** —— 这两根一定按上表，别凭记忆。
> ⚠️ **编码器 VCC 一律接 3.3V**：信号接 `PB6`–`PB9`，STM32 的 IO 一律不耐 5V；而且 `PA0`–`PA7` 现在全给循迹 ADC 了。**本手册旧版写"数不到脉冲可改 5V"是错的，已删。**
> ✅ **左编码器**在 `PB6/PB7` = **TIM4 硬件编码器**，STM32 自动四倍频，不用写中断。
> ⚠️ **右编码器**在 `PB8/PB9`，只能走 **EXTI9_5 中断软件计数**（TIM3 的 CH1/CH2 在 `PA6/PA7`，被循迹占了）。MG310 一圈约 330 脉冲，1 m/s 时每秒几千次中断，72MHz 扛得住，但要写得干净（中断里只做计数，别做运算）。

要点：
- 编码器线**尽量短、别和电机功率线并排走**，最好隔开 2cm 以上，不然脉冲会被干扰。
- 有些编码器是**开漏输出**，需要外部上拉 10kΩ 到 3.3V，没上拉时读数一直是 0。现象：串口打印的计数永远是 0。

**✅ 验收 E**：串口打印脉冲计数，用手慢慢转轮子，数字应该连续往上/往下跳；正反转方向相反。

## 8. 阶段 F：循迹传感器（W46–W55）

> ✅ **已确认（10-30 晚，看商品页）：你们买的是模拟版。**
> 红色板 66×16 mm、**背面没有电位器**、参数写"输出信号：模拟量 / 遮挡时 D1–D8 电压下降，变化范围在 1V 内"。
> 所以 **必须接 `PA0`–`PA7` 进 ADC**（`PB0` `PB1` `PB5`–`PB10` 一个 ADC 通道都没有，模拟量接上去只会读到 4095 或乱跳）。
> ⚠️ 这一改**连带挪动另外 6 根线**（左电机方向 + 两个编码器），见 8.4 —— 不是只改循迹那 8 根。

![图 3　8 路循迹 D1–D8 → PA0–PA7（ADC1_IN0–IN7），串口 / SWD 烧录](图/图3-循迹串口烧录.png)

### 8.1 接线表（模拟版）

| 线号 | 模块脚 | → STM32 引脚 | 备注 |
|---|---|---|---|
| W46 | `VCC` | 面包板 **3.3V 轨** | **必须 3.3V**，见下方红字 |
| W47 | `GND` | 面包板 **GND 轨** | |
| W48 | `D1`（最左） | **`PA0`** | ADC1_IN0 |
| W49 | `D2` | **`PA1`** | ADC1_IN1 |
| W50 | `D3` | **`PA2`** | ADC1_IN2 |
| W51 | `D4` | **`PA3`** | ADC1_IN3 |
| W52 | `D5` | **`PA4`** | ADC1_IN4 |
| W53 | `D6` | **`PA5`** | ADC1_IN5 |
| W54 | `D7` | **`PA6`** | ADC1_IN6 |
| W55 | `D8`（最右） | **`PA7`** | ADC1_IN7 |
| W56 | `IR` | 面包板 **3.3V 轨** | 低电平=关掉全部红外管；**悬空可能自激乱跳**，接 3.3V 最稳 |

> 🔴 **只能 3.3V 供电，不能 5V。** 模块标"3.3–5V"，但 5V 供电时常态输出约 5V、遮挡时约 4V，**都超过 STM32 的 ADC 上限 3.3V**，`PA0`–`PA7` 会被打坏。3.3V 供电时常态 ≈3.3V、遮挡 ≈2.3V，正好在量程内。
> 🔍 接完先量模块 `VCC` 对 `GND` = 3.3V 左右，再插 `D1`–`D8`。

### 8.2 模拟版怎么读（4 个要点）

1. **供电必须是 3.3V**（见上）。3.3V 同时就是 ADC 参考电压，`VREF+` 不用另接。
2. **8 通道扫描 + DMA**，不要逐路 `HAL_ADC_PollForConversion` 轮询（8 路轮询会互相踩，读数越读越怪）。
3. **`PA0`–`PA7` 不要开内部上拉/下拉**，模拟脚开上拉会把读数整体拉偏。
4. **阈值必须实测，别抄别人的 2000。** 商品页写"变化范围在 1V 内"——即白线与蓝底的差可能只有 0.3–1.0V（ADC 差 370–1240）。做法：
   - 串口把 8 路原始值全打出来；
   - 车放蓝底上记一组（常态高值），用白胶带盖住某一路再记一组（低值）；
   - 阈值取两组中间，再留 ±20% 迟滞，防止在线上来回抖。

### 8.3 传感器高度（决定成败）
- 红外对管离地 **10–15mm**，垂直朝下，不要歪。
- 模块是 **66×16mm、两个 φ3 固定孔、孔距 36mm** —— 先在底盘上找孔，没有就钻两个 3mm 孔，或用尼龙柱垫到合适高度。
- 装好后**必须用"蓝底 + 20mm 白胶带"实测**（采购清单里已经标了：这是第一优先级的事）。

### 8.4 换了模拟版，另外 6 根线也要跟着挪

`PA0`–`PA7` 全被 ADC 占了，原来占这些脚的都得让位：

| 功能 | 改之前 | **改之后（照这个接）** |
|---|---|---|
| 左电机方向 BIN1/BIN2 | `PA2` `PA3` | **`PB14` `PB15`** |
| 左编码器 A/B | `PA0` `PA1`（TIM2） | **`PB6` `PB7`（TIM4 硬件编码器）** |
| 右编码器 A/B | `PA6` `PA7`（TIM3） | **`PB8` `PB9`（EXTI9_5 软件四倍频）** |
| 循迹 D1–D8 | `PB0` `PB1` `PB5`–`PB10` | **`PA0`–`PA7`（ADC）** |
| 右电机 PWM / 方向 | `PA8` / `PB12` `PB13` | 不变 |
| 左电机 PWM | `PA11` | 不变 |

代价：右编码器失去硬件编码器，要写 `EXTI9_5_IRQHandler` 手动四倍频计数。能用，只是 CPU 更忙。

> 换模块 vs 改线：数字版模块十几块钱，换掉能省 6 根线 + 一段中断代码。**但你们已经买好了，就按上面改，别折腾退货。**

**✅ 验收 F**：
- 串口打印 8 路 ADC 原始值：**蓝底上 8 路都是高值（约 3800–4095），白胶带盖住的那一两路明显掉下来（约 2000 以下）** → 成功
- ⭐ 注意逻辑方向：你们是**白线**（20mm 白胶带贴在蓝底上），**白=低值**。和网上"黑线模块"的默认逻辑相反，抄代码别抄错。

## 9. 阶段 G：上电/断电顺序（背下来）

**上电（每一级之间停 2 秒，眼睛看有没有冒烟/闻到糊味立刻断电）：**
```
1. 检查：所有电源线正负极没反接、没短路（蜂鸣档）
2. 电池接上（开关 OFF）
3. 开 KCD1 → 量 5V 轨 = 5.0V，3.3V 轨 = 3.3V
4. 插 USB-TTL（先插隔离器，再插 USB）
5. 最后才轮到"跑程序"
```

**断电：完全反过来**
```
1. 程序停止
2. 拔 USB
3. 关 KCD1
4. 再拆线
```

**调试三不要：**
- 不要带电插拔电机 6P 插头（会打火，可能烧驱动）
- 不要带电改杜邦线（尤其 3.3V 和 GND）
- 不要轮子着地做第一次电机测试

## 11. 施工顺序（时间线，照这个做）

| 阶段 | 干什么 | 预计 | 谁做 | 做完的标志 |
|---|---|---|---|---|
| **P0** | 清点配件、确认第 0 节 5 件事、量电池电压 | 30 min | 全员 | 缺件清单出来 |
| **P1** | 机械装配：电机上底盘 → 轮子 → 万向轮 → 铜柱架板 → 传感器支架 → 电池/开关固定 → 理线 | 1.5 h | 2 人 | 车能推着走，轮子不摩擦底盘 |
| **P2** | 电源系统（W01–W10）+ 调压 | 40 min | 会用电烙铁的人 | 万用表 5.0V，见验收 A |
| **P3** | 主控上电（W11–W14） | 20 min | 同一人 | 3.3V 正常，见验收 B |
| **P4** | 烧录 + 串口（W16–W23） | 1 h | 写代码的人 | 点灯 + 串口打印，见验收 C |
| **P5** | 电机驱动（W24–W37）+ 免编程验线 | 1 h | 2 人 | 两轮能正反转，见验收 D |
| **P6** | 编码器（W38–W45）+ 计数打印 | 40 min | 写代码的人 | 手转轮子计数跳，见验收 E |
| **P7** | 循迹（W46–W55）+ 蓝底白线实测 | 1 h | 2 人 | 8 路读数区分蓝底/白线，见验收 F |
| **P8** | 第一次落地上线、限速 30%、调 PID | 整天 | 全员 | 能沿直线跑 2 米不冲出去 |

**机械装配（P1）细步骤：**
1. 两个 MG310 装到底盘尾部，电机轴朝外，用 M3 螺丝 + 螺母固定（先别拧死，位置对齐再紧）。
2. 轮毂压进轮胎，再压到电机轴上（有的要顶丝，拧紧）。
3. 万向轮装底盘前部正中，高度调到和两个驱动轮**同一水平面**（车放桌上不晃）。
4. M3 铜柱固定在底盘上，STM32 板/面包板架在上面 —— **不要让焊点和金属底盘接触**。
5. 循迹支架装车头最前端，探头离地 10–15mm（用垫片/铜柱调）。
6. 电池用扎带固定在底盘中部（重心低、居中），KCD1 装在后部或侧面，方便手够到。
7. 线束用扎带分三束：**电源粗线、电机线、信号线**，分开走，别缠在轴上。
8. 检查：推车走，看有没有线被轮子咬到。

## 12. 引脚占用表 & 禁区

| 用途 | 引脚 | 备注 |
|---|---|---|
| **右** PWM | `PA8` | **TIM1_CH1**（高级定时器，必须开 MOE） |
| **左** PWM | `PA11` | **TIM1_CH4**（同上；PA11 也是 USB D−） |
| **右**方向 | `PB12` `PB13` | AIN1 / AIN2 |
| **左**方向 | `PB14` `PB15` | BIN1 / BIN2 |
| **左**编码器 | `PB6` `PB7` | **TIM4 硬件编码器** |
| **右**编码器 | `PB8` `PB9` | **EXTI9_5 软件四倍频**（TIM3 被循迹占用） |
| 循迹 8 路 | `PA0`–`PA7` | **模拟版，ADC1_IN0–IN7**；`IR` 脚接 3.3V |
| 调试串口 | `PA9` `PA10` | USART1 |
| 烧录 | `PA13` `PA14` | **SWD，永远别挪作他用** |

**禁区（别拿来接东西）：**
- `PA13` `PA14` —— 一动就再也烧不进程序
- `PA11` `PA12` —— USB（D−/D+）；`PA11` 现在借给左电机 PWM，**就不能再用 USB 虚拟串口了**
- `PB2` —— BOOT1，决定启动方式
- `PC13` `PC14` `PC15` —— 驱动能力弱、只能低速用，`PC14/15` 还接晶振
- `PB4` `PB3` `PA15` —— JTAG 脚，默认不能当普通 IO（关掉 JTAG 才可用）
- `PA0`–`PA7` —— **现在全部给循迹 ADC**，别再拿去做数字输出（输出会污染模拟通道）

## 13. 故障排查表（照着现象找）

| 现象 | 最可能的原因 | 怎么办 |
|---|---|---|
| ST-LINK 找不到芯片 | 3 根线接错 / 3.3V 冲突 / BOOT0=1 | 只接 SWDIO/SWCLK/GND；BOOT0 跳线到 `0`；把 SWD 速度降到 1MHz；按住 RESET 再点下载 |
| 烧录后不运行 | 复位没按 / 程序跑飞 | 按 RESET；串口看有没有打印卡在哪 |
| 串口乱码 | 波特率不对 / TX-RX 没交叉 / 没共地 | 115200；TX→PA10、RX→PA9；补 GND |
| 串口收不到任何东西 | PA9/PA10 接反 / 隔离器没供电 | 对调试；隔离器插上 micro-USB 供电 |
| 电机完全不转 | **STBY 没拉高（占 80%）** / VM 没电 / PWM 没给 | 先量 STBY 是不是 3.3V；量 VM 是不是 7.4V |
| 电机只往一个方向转 | AIN1/AIN2 有一根没接好 | 用免编程验线法逐个试 |
| 电机转一下就停 / 驱动发烫 | 堵转 / PWM 给到 100% | PWM 锁 70%；减负载；查轮子是否摩擦底盘 |
| 程序上电就跑飞、复位不干净 | 电机干扰、地线太细、编码器线太长 | 电机电源线用 22AWG；传感器/编码器线缩短；在 TB6612 VM 附近加 100µF 电解 |
| 编码器计数一直 0 | 编码器 VCC 没接 / 开漏没上拉 / A、B 接反 | 量 5 脚对 GND 是不是 3.3V（**别改 5V**）；加 10k 上拉；A/B 对调 |
| 编码器计数乱跳 | 干扰 | 线缩短、远离电机线、加 100nF 到地 |
| 循迹 8 路读数全一样 | 供电不对 / 高度不对 / 插成了非 ADC 脚 | 模拟版必须 3.3V 且接 `PA0`–`PA7`；高度 10–15mm |
| 循迹读数全是 4095 | 接了 5V 供电 / 没接 GND / 模块 `IR` 悬空被拉低 | 换 3.3V；补 GND；`IR` 接 3.3V |
| 循迹读数全是 0 | 插在了 `PB0` `PB1` `PB5`–`PB10`（**没有 ADC**） | 挪到 `PA0`–`PA7` |
| 8 路读数互相干扰、越读越怪 | 逐路轮询 ADC，没上 DMA | 改 8 通道扫描 + DMA |
| 循迹把蓝底当白线 | 阈值不对 / 反光 | 重新采阈值；避开正对环境光 |
| 一开电机 STM32 就复位 | 电池电压被拉低 / 共地不良 | 电池充满；加 100µF；检查地线是不是只靠一根杜邦线 |

## 15. 给写代码的人的引脚宏（直接抄）

```c
/* ---- 电机：TB6612（A 通道 = 右轮，B 通道 = 左轮）---- */
#define PWMA_PIN   GPIO_PIN_8    /* PA8   TIM1_CH1  → 右轮速度 */
#define PWMB_PIN   GPIO_PIN_11   /* PA11  TIM1_CH4  → 左轮速度 */
#define AIN1_PIN   GPIO_PIN_12   /* PB12  右轮方向 */
#define AIN2_PIN   GPIO_PIN_13   /* PB13  右轮方向 */
#define BIN1_PIN   GPIO_PIN_14   /* PB14  左轮方向 */
#define BIN2_PIN   GPIO_PIN_15   /* PB15  左轮方向 */

#define SPEED_R    (&htim1)      /* TIM1_CH1 = PA8  */
#define SPEED_L    (&htim1)      /* TIM1_CH4 = PA11 */

/* ---- 编码器 ----
   左：PB6/PB7 = TIM4 硬件编码器（自动四倍频）
   右：PB8/PB9 = EXTI9_5 软件四倍频（TIM3 的 CH1/CH2 在 PA6/PA7，被循迹占了）*/
#define ENC_L_A    GPIO_PIN_6    /* PB6  TIM4_CH1 */
#define ENC_L_B    GPIO_PIN_7    /* PB7  TIM4_CH2 */
#define ENC_R_A    GPIO_PIN_8    /* PB8  EXTI8 */
#define ENC_R_B    GPIO_PIN_9    /* PB9  EXTI9 */

/* ---- 循迹 8 路（模拟版：ADC1_IN0–IN7，8 通道扫描 + DMA）---- */
/* PA0 PA1 PA2 PA3 PA4 PA5 PA6 PA7；模块 IR 脚接 3.3V 常开 */
#define TRACK_CH_NUM   8
#define TRACK_ADC_MAX  4095    /* 12 位满量程 */

/* ---- 串口 USART1 ---- */
/* PA9 = TX, PA10 = RX, 115200 8N1 */

/* ---- 限速保护 ---- */
#define PWM_MAX  0.70f   /* TB6612 1.2A < MG310 堵转 2A，锁 70% */
```

> ⚠️ **TIM1 是高级定时器**：初始化完 PWM 之后必须打开主输出，否则引脚一直是低电平：
> ```c
> HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_1);
> HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_4);
> __HAL_TIM_MOE_ENABLE(&htim1);   /* ← 漏了这一句，电机永远不转 */
> ```
> 方向宏（因 A 通道接右轮、AO1→M+）：
> ```c
> #define RIGHT_FWD()  do{ AIN1_H(); AIN2_L(); }while(0)   /* 右轮前进 */
> #define RIGHT_BACK() do{ AIN1_L(); AIN2_H(); }while(0)
> #define LEFT_FWD()   do{ BIN1_H(); BIN2_L(); }while(0)   /* 左轮前进 */
> #define LEFT_BACK()  do{ BIN1_L(); BIN2_H(); }while(0)
> ```
> 实车发现某一轮反了就对该轮的两个宏取反，**别去拆线**。
>
> ⚠️ **这套宏有个前提：右电机的 `AO1`→`M+(1 脚)`。** 你们目前接的是 `AO1`→`M−(6 脚)`（见《接线复核-2026-10-30.md》5b）。
> - 已经把 `AO1`/`AO2` 两根线对调过 → 直接用上面的宏。
> - 还没对调 → 右轮的那两条要先按反的写：`RIGHT_FWD() = AIN1_L() + AIN2_H()`。
>
> 两种写法二选一，**别靠猜**：上电前把轮子架空，PWM 给 20% 空转看一次方向，反了就在代码里对调，不要拆线。
