# 八路循迹模块 —— 输出方式说明（给写代码的队友）

> 最后更新：2026-11-13 20:10　对应固件：`代码\analog\analog_route.c` v0.8.0（实测 8 路读数正常）
> 一句话：**模块不是数字口，是「8 选 1 模拟开关 + 一根模拟输出线」，8 路要靠 3 根地址线轮流选中，再用 1 个 ADC 脚读。**

---

## 1. 模块上有什么

| 引脚 | 方向 | 说明 |
|---|---|---|
| `AD0` | 输入（MCU→模块） | 通道地址最低位（LSB） |
| `AD1` | 输入（MCU→模块） | 通道地址中位 |
| `AD2` | 输入（MCU→模块） | 通道地址最高位（MSB） |
| `OUT` | 输出（模块→MCU） | **公共模拟输出**，输出当前被选中那一路的电压 |
| `VCC` | 电源 | 模块标 5V（实测 OUT 满幅只有 3.3V） |
| `GND` | 地 | 必接 |
| `EN` / `INH`（有的话） | 输入 | 接 GND（常通） |

板载是一颗 **CD4051（八选一模拟开关）**。所以：**8 路探头，只占 1 个 ADC 脚 + 3 个 GPIO。**

通道选择：`AD2 AD1 AD0` = `000` → 第 1 路，`001` → 第 2 路，… `111` → 第 8 路。

---

## 2. 现在车上的接法

| 模块脚 | STM32 引脚 | 配置 |
|---|---|---|
| AD0 | PA0 | 推挽输出 50MHz |
| AD1 | PA1 | 推挽输出 50MHz |
| AD2 | PA2 | 推挽输出 50MHz |
| OUT | PA3 | 模拟输入（ADC1_IN3） |

代码里的对应宏（`analog_route.c` 顶部）：

```c
#define MUX_AD0 0
#define MUX_AD1 1
#define MUX_AD2 2
#define MUX_OUT_PIN 3
#define ADC_CH 3          /* PA3 = ADC1_IN3 */
```

**想换脚**：`GPIOA->CRL` 里改对应 nibble（`0x3`=推挽输出，`0x0`=模拟输入），并改 `ADC_CH`。
注意 **PA0–PA7、PB0/PB1 才有 ADC 且都不耐 5V**；**PA8–PA15、PB2–PB15 耐 5V 但没有 ADC**，两者不重叠。

## 3. 读一路的完整流程（照抄即可）

```c
mux_select(ch);                       /* 1. 选通道：写 ODR 低 3 位 + 等 ~2µs */
ADC1->SQR3 = ADC_CH;                  /* 2. 指定 ADC 通道 */
ADC1->CR2 |= (7u << 17) | ADC_CR2_EXTTRIG;   /* 3. EXTSEL = SWSTART(111) */
ADC1->CR2 |= ADC_CR2_SWSTART;                /* 4. 产生一次触发 */
busy_us(60);                          /* 5. 等 ~40µs */
uint16_t v = ADC1->DR & 0x0FFFu;      /* 6. 直接读结果 */
```

> ⚠️ **第 3、4 步不能合成 "只写 SWSTART"**。本项目实测：只写 `SWSTART` 时这颗片子
> 根本不启动转换（`SR=0 / DR=0`），必须先设 `EXTSEL=111` 再置 `EXTTRIG`，最后写 `SWSTART`。

`mux_select()`：

```c
GPIOA->ODR = (GPIOA->ODR & ~0x0007u) | (ch & 0x07u);
for (volatile uint32_t k = 0; k < 60u; k++) { __NOP(); }   /* 等模拟开关稳定 */
```

一轮 8 路约 `8 × (2 + 25)µs ≈ 220µs`，2ms 控制周期里占 11%，可以接受。

## 4. ⚠️ 三个必须知道的坑（本项目实测）

### 坑 1：**触发方式不对，转换根本不启动**

```c
ADC1->CR2 |= ADC_CR2_SWSTART;   /* ❌ 单独写这一位，实测转换不启动，DR 永远是 0 或垃圾值 */
```

2026-11-13 用 7 种方式穷举出来的结果（这颗片子 `DBGMCU IDCODE` 读回 **0**，是兼容片，不是原厂 F103）：

| 触发方式 | 结果 |
|---|---|
| 只写 `SWSTART` | ❌ `SR=0 DR=0` |
| `EXTTRIG + EXTSEL=111` 再 `SWSTART` | ✅ `SR=18 DR=4084` |
| ADON 连续写两次 | ✅ `SR=18 DR=4077` |
| 连续模式 `CONT` | ❌ `SR=0 DR=0` |
| 先校准再 `SWSTART` | ✅ 也能启动 |

**结论：每次读都必须走 EXTTRIG 那条路**（见第 3 节代码）。

### 坑 1b：**不能等 EOC**

即使转换启动了，这颗片的 `EOC` 也时有时无、`STRT` 会一直挂着。
统一做法：**触发后固定等 60µs，直接读 DR**，不要写 `while (!(ADC1->SR & EOC))`——
那会死等，表现为「打完 banner 车就不动了」。

### 坑 2：**必须先校准，否则根本不转换**

```c
ADC1->CR2 |= ADC_CR2_ADON; delay_ms(10);   /* 稳定时间给足，1ms 不够 */
ADC1->CR2 |= ADC_CR2_RSTCAL; delay_ms(5);
ADC1->CR2 |= ADC_CR2_CAL;    delay_ms(5);
ADC1->CR2 = ADC_CR2_ADON;                  /* 校准后重写 ADON */
```

用 `delay_ms` 等，**不要** `while (CR2 & CAL)` 死等——这颗片的标志位同样不可靠。

### 坑 3：**时钟与采样时间**

```c
RCC->CFGR  |= ADCPRE /6;      /* ADCCLK = 72/6 = 12MHz，别超 14MHz */
ADC1->SMPR2 = 0x00924924;     /* ch0–ch7 都是 55.5 周期 */
```

8 路模拟开关输出阻抗高，采样时间短了读数会飘，55.5 周期是稳的。

## 5. 读到的数值代表什么

**极性是反的（蓝底高、白线低）**：

| 场景 | OUT 电压 | ADC 读数（12 位） |
|---|---|---|
| 探头在蓝底上 | ≈ 3.3V（满幅） | ≈ 4050–4095 |
| 探头压白线 | 更低（待实测记录） | 明显更小 |

所以「**白度高 = 读数小**」，和常见的白底黑线模块正好相反。

代码里的换算（`whiteness()`）：

```c
white = (adc - blk) * 1000 / (wht - blk);   /* 蓝底≈0，白线≈1000 */
```

`blk` = 蓝底基准（默认 3600）、`wht` = 白线基准（默认 700），按 `k` 键标定后会重写。

**判偏差**：按白度做加权重心 `e = Σ(v[i]·W[i]) / Σv[i]`，`W = {-35,-25,-15,-5,5,15,25,35}`；
`Σv < 800` 视为「全蓝、丢线」。

## 6. 队友接手时的检查清单

1. 上电串口应打印 `adc now: 4050 4052 ...`（8 个都在 4000 上下 = 全在蓝底）。
2. **用白纸只挡住第 1 个探头**，第 1 个数应明显掉下来，其余 7 个不动 → 4051 通道切换正常。
3. 8 个数一起变 → AD0/AD1/AD2 接错或虚焊。
4. 一个都不变 → 又是回到「等 EOC」或者没校准。
5. 串口输出**只许 ASCII**，中文会变乱码（源码 UTF-8，XCOM 按 GBK 解）。
