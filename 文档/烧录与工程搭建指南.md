# 从零到跑起来：CubeMX 工程 + 烧录 + 串口验证

> 适用：STM32F103C8T6（Blue Pill）+ ST-LINK V2 + USB-TTL（CH340）
> 目标：烧进第一个程序，串口能看到循迹 8 路和编码器读数

---

## 0. 你的硬件现状（已实测确认）

| 项 | 状态 |
|---|---|
| 5V 供电 | 5.0V ✓ |
| 3.3V 供电 | 3.25V ✓ |
| 循迹 X1–X8 | 收到反射 → **3.3V**，收不到 → **0V** ✓ |
| 编码器 A/B | 静止时一个 0V、一个 3.3V ✓（正交相位） |
| TB6612 输出 AO/BO | 全 0V ✓（没跑程序时正常） |
| 电机 | 未通电不转 ✓ |

**极性记牢（2026-11-02 实测更正）**：

| 场景 | X1–X8 电平 |
|---|---|
| **白线**（强反射） | **3.3V = 1**（压线） |
| **蓝底 / 黑线**（弱反射） | **0V = 0**（没压线） |
| 悬空对着空气 | 0V（收不到反射） |
| 手掌贴近 | 3.3V（近距离强反射，等效于压白线） |

即：**收到反射 = 1 = 压线**。`track_io.h` 里 `TRACK_IO_LINE_IS_1` 保持 **1**。

## 2. CubeMX 逐项配置（照着点）

### 2.1 新建工程

1. `File → New Project` → 搜索 `STM32F103C8` → 选 **STM32F103C8Tx**
2. 弹出 "MCU Selector" 确认后点 **Start Project**

### 2.2 系统核心

| 位置 | 设置 |
|---|---|
| **System Core → SYS** | `Debug: Serial Wire` ← **必选，否则下次烧不进去** |
| **System Core → RCC** | `High Speed Clock (HSE): Crystal/Ceramic Resonator` |
| **System Core → RCC** | `Low Speed Clock (LSE): Disable` |

### 2.3 时钟树（Clock Configuration）

- 输入源选 **HSE**
- `PLL Source: HSE`，`PLLMul: ×9`
- `System Clock Mux: PLLCLK`
- 确认：**HCLK = 72 MHz**，APB1 = 36 MHz，APB2 = 72 MHz，ADC = 12 MHz

> 如果晶振不起振（烧录后不跑），把 HSE 改成 `Bypass` 或改用 HSI×PLL（64MHz）。见文末排查表。

### 2.4 引脚分配（Pinout 视图直接点）

| 引脚 | 功能 | 配置 |
|---|---|---|
| **PA0–PA7** | 循迹 X1–X8 | `GPIO_Input`，No pull-down/up |
| **PB12** | AIN1（右轮方向） | `GPIO_Output`，Low speed |
| **PB13** | AIN2 | `GPIO_Output` |
| **PB14** | BIN1（左轮方向） | `GPIO_Output` |
| **PB15** | BIN2 | `GPIO_Output` |
| **PA8** | PWMA（右轮） | `TIM1_CH1` |
| **PA11** | PWMB（左轮） | `TIM1_CH4` |
| **PB6 / PB7** | 左编码器 A/B | `TIM4_CH1` / `TIM4_CH2` |
| **PB8 / PB9** | 右编码器 A/B | `GPIO_EXTI8` / `GPIO_EXTI9` |
| **PA9 / PA10** | 串口调试 | `USART1_TX` / `USART1_RX` |
| **PC13** | 板载 LED | `GPIO_Output` |

### 2.5 定时器

**TIM1（PWM，高级定时器）**

| 项 | 值 |
|---|---|
| Clock Source | Internal Clock |
| Channel1 | PWM Generation CH1 |
| Channel4 | PWM Generation CH4 |
| Prescaler | **71**（72MHz / 72 = 1MHz） |
| Counter Period | **999**（1kHz PWM） |
| Pulse（CH1/CH4） | 0 |
| **MOE** | 代码里必须 `__HAL_TIM_MOE_ENABLE(&htim1)`，否则无输出 |

**TIM4（左编码器）**

| 项 | 值 |
|---|---|
| Combined Channels | **Encoder Mode** |
| Encoder Mode | TI1 and TI2 |
| Prescaler | 0 |
| Counter Period | 65535 |

### 2.6 中断

`NVIC` 里勾选：

- `EXTI line[9:5] interrupts` → Enable（右编码器 PB8/PB9）
- `USART1 global interrupt` → Enable（如果用中断接收；本程序用轮询发，可不勾）

### 2.7 生成代码

`Project Manager`：

- `Toolchain / IDE: MDK-ARM`，Version 选你装的（V5）
- `Code Generator` 里勾 **Generate peripheral initialization as a pair of .c/.h files**

点 **GENERATE CODE** → 用 Keil 打开生成的工程。

## 4. main.c 里插代码（只改 USER CODE 段）

CubeMX 生成的 `main.c` 里有 `/* USER CODE BEGIN ... */` 标记，**只在这些标记之间写**，重新生成代码不会丢。

### 4.1 文件顶部（`USER CODE BEGIN Includes`）

```c
#include "self_test.h"
#include "track_io.h"
```

### 4.2 在 `main()` 里，`while (1)` 之前（`USER CODE BEGIN 2`）

```c
    /* TIM1 是高级定时器，必须使能主输出，否则 PA8/PA11 没有 PWM */
    __HAL_TIM_MOE_ENABLE(&htim1);
    HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_1);
    HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_4);
    HAL_TIM_Encoder_Start(&htim4, TIM_CHANNEL_ALL);

    self_test_init();      /* 心跳 + 编码器 EXTI 已由 CubeMX 生成 */
```

### 4.3 在 `while (1)` 里（`USER CODE BEGIN WHILE`）

```c
    self_test_loop();      /* 10Hz 打印 trk/enc，1 秒心跳 */
```

### 4.4 外部中断回调（`USER CODE BEGIN 4`，文件末尾）

```c
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    self_test_encoder_isr(GPIO_Pin);   /* PB8/PB9 右编码器四倍频 */
}
```

## 5. 编译 + 烧录

### 5.1 接线（ST-LINK → STM32，只接 3 根）

| ST-LINK | STM32 | 说明 |
|---|---|---|
| `SWDIO` | `PA13`（板端 SWD 针） | 数据 |
| `SWCLK` | `PA14` | 时钟 |
| `GND` | `GND` | 共地 |
| **`3.3V`** | **不接** | 板子自己有电，同时供会打架 |

### 5.2 Keil 设置

`Options for Target → Debug`：

- 选 **ST-Link Debugger**
- 点 `Settings` → `Port: SW`，能识别到 `STM32F103 Medium-density` 就通了
- `Flash Download` 里勾 `Reset and Run`

### 5.3 烧

- `F7` 编译（0 error）
- `F8` 下载

> **第一次烧不进去**：按住板上的 RESET，点下载，看到 "Connecting" 就松开。

## 6. 串口验证

### 6.1 接线（USB-TTL → STM32）

| USB-TTL | STM32 |
|---|---|
| `TXD` | `PA10`（RX） |
| `RXD` | `PA9`（TX） |
| `GND` | `GND` |
| `VCC` | **不接** |

### 6.2 看输出

串口助手：**115200，8N1**，应该每 100ms 看到：

```
trk=00000000 encL=    0 encR=    0
trk=00000000 encL=    0 encR=    0
```

- **手挡循迹某一路** → `trk=` 对应位变 1
- **手转左轮** → `encL` 数字变化
- **手转右轮** → `encR` 数字变化
- PC13 蓝灯每秒翻转

三个都对上 = **硬件 + 烧录 + 串口全部打通**，可以开始写循迹 PID 了。

## 7. 排查表

| 现象 | 原因 | 修法 |
|---|---|---|
| 烧录时报 "No target connected" | PA13/PA14 被复用 / 没共地 | 按住 RESET 再下载；检查 GND |
| 烧进去了但没反应 | HSE 晶振不起振 | CubeMX 里改用 HSI+PLL（64MHz） |
| 串口全是乱码 | 波特率不对 | 115200，8N1 |
| 串口没输出 | PA9/PA10 接反 | TXD↔PA10、RXD↔PA9（交叉） |
| `trk` 恒为 11111111 | 循迹模块没供电或接反 | 量模块 5V 脚 |
| `encL` 不变 | TIM4 编码器模式没开 / A/B 接反 | 检查 CubeMX TIM4 设置 |
| `encR` 不变 | EXTI 没使能 / 回调没写 | 检查 NVIC + `HAL_GPIO_EXTI_Callback` |
| 电机不转 | MOE 没使能 | `__HAL_TIM_MOE_ENABLE(&htim1)` |
| 电机只朝一个方向转 | 方向脚接线与代码不一致 | 对调 AIN1/AIN2 或改代码 |
