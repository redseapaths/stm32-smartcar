# STM32 智能车 · 红外循迹 + 里程闭环（2026 校赛）

一套从零写起的 STM32F103 循迹智能车固件：**裸寄存器、无 HAL、单文件主程序**，
在 2913cm 赛道上以 **1 分 35 秒**完赛（平均 30.2 cm/s，0 罚时）。

```
赛道：2913cm / 28 个弯（26×90° + 2×30°）+ 1 个环岛
成绩：1:35（校赛）· 开发期 2:30 → 1:40 → 1:35
```

---

## 一、这套代码做了什么

| 模块 | 做法 |
|---|---|
| 巡线 | 8 路红光灰度（模拟量），加权质心求横向偏差 `e`，PD 控制转向 |
| 直行 | 里程达目标 + PID 纠偏，两者解耦：**里程管"走多远"，PID 管"别跑偏"** |
| 转弯 | 原地转，两轮差分量测角：`d = (dl - dr) / 2`，对停车前滑免疫 |
| 找线 | 转完没看到线 → 原地左右扫（±30°/±60°/反向 90°），扫不到就后退 5cm 再扫 |
| 岔路 | 连续压线的"簇"里只取离上一帧最近的一簇，避免质心被岔口拉偏 |
| 禁止 PID 区间 | 按段号 + 里程区间关掉 PID（穿虚线、过岔口时纯直行） |
| 调试 | 串口单字符命令：`g` 开始 / `c` 看 8 路原始值 / `t` 电机自检 / `s18` 从第 18 段跑 / `o18` 只跑第 18 段 |

## 二、硬件

- 主控：STM32F103C8T6 最小系统板（兼容片，见「坑」第 2 条）
- 驱动：TB6612FNG（A 通道 = 右轮，B 通道 = 左轮，故意反着接）
- 电源：2S 18650（7.4V）→ LM2596 降 5V 给 MCU，电机直取母线
- 传感：8 路红光灰度模块，**CD4051 八选一**复用到一个 ADC 通道
- 编码器：左右轮各一只，左轮 TIM4 硬件四倍频，右轮 EXTI 软件四倍频

| 功能 | 引脚 |
|---|---|
| 循迹 | AD0/AD1/AD2 → PA0/PA1/PA2，OUT → PA3（ADC1_IN3） |
| 右轮 PWM | PA8（TIM1_CH1） |
| 左轮 PWM | PA11（TIM1_CH4） |
| 右轮方向 | PB12 / PB13（AIN1 / AIN2） |
| 左轮方向 | PB14 / PB15（BIN1 / BIN2） |
| 左编码器 | PB6 / PB7（TIM4 编码器模式） |
| 右编码器 | PB8 / PB9（EXTI9_5） |
| 串口 | PA9 / PA10（USART1，115200 8N1） |
| 下载 | PA13 / PA14（SWD） |

## 五、踩过的坑（这些才是最有价值的部分）

1. **编码器符号相反**：两轮同向转却一正一负，`(|dl|+|dr|)/2` 平均后里程恒为 0，
   表现为"车在走但里程不涨、走几毫米就判丢线"。修：`ENC_RIGHT_SIGN = +1`。
2. **兼容片 ADC 的 EOC 不可靠**：`idcode=0` 的 CS32/APM32 一类芯片，
   只写 `SWSTART` 不启动转换，`EOC` 永不置位。必须
   `SQR3 = ch; CR2 |= (7<<17) | EXTTRIG; CR2 |= SWSTART;` 再定时读 `DR`。
3. **8 路 bit 镜像**：压最左的探头读回最右一位。`0x18` 恰是回文所以一直没暴露。
4. **转弯角度被"前滑"污染**：用 `(|dl|+|dr|)/2` 累加，停车后前滑几厘米也算成已转角度，
   于是"一上来就白送 6cm"，90° 只转到 55°。改用差分量 `(dl-dr)/2` 后精确。
5. **禁止 PID 区间出口是阶跃**：`STEER_MAX 400 > SPEED_LEG 420` 时内轮被
   `WHEEL_MIN 150` 顶回，实际可用差速只剩 270，等于"打不出方向"，出口 3–4cm 就丢线。
6. **串口中文乱码**：源文件是 UTF-8，串口助手按 GBK 解 → 固件串口输出一律用 ASCII。

## 六、编译与烧录

**环境**：Keil MDK 5（ARM Compiler V6）+ STM32F1xx_DFP 设备包。

1. 打开 `代码/analog.uvprojx`（工程已配好：源码 `.\analog\analog_route.c`、启动文件在 `RTE\`）；
2. 首次打开如果提示缺 Device 组件，装一下 Pack Installer 里的 `Keil::STM32F1xx_DFP`；
3. F7 编译 → 输出 `Objects/analog/analog.hex`；
4. ST-Link（SWD：3.3V / GND / SWDIO→PA13 / SWCLK→PA14）下载，或直接烧 `固件/analog.hex`。

编译结果参考：`Code=18,552 B · RO=4,256 B · RW=32 B · ZI=1,704 B`（Flash 64KB 的 29%、RAM 20KB 的 8%）。
Target 的优化等级是 `-O0`（赛前不优化，方便单步调试；改 `-O1` 能再省 ~2KB，但要重标 PID）。

**串口**：PA9(TX) → USB-TTL 的 RXD，115200 8N1。上电后可用单字符命令：

| 键 | 作用 |
|---|---|
| `g` | 立刻开始跑（否则 1 秒后自动开始） |
| `c` | 打印 8 路原始值 + 白度 + 偏差，用于现场标定 |
| `t` | 电机自检（LEFT / RIGHT / BOTH 各 1.2 秒，打印各自里程） |
| `k` | 重新做模拟量标定（蓝底 + 白线两步） |
| `s18` / `o18` | 从第 18 段跑到尾 / 只跑第 18 段 |
| `xx` | 600ms 内连按两次 `x` 紧急停车 |

## 七、预编译固件

`固件/analog.hex` 就是校赛 1:35 那一版（v2.0.0，与 `代码/analog/analog_route.c` 完全对应），
可以直接用 ST-Link Utility / Keil / STM32CubeProgrammer 烧进板子，不需要编译。

⚠️ 换到自己的车上前必须先改这几个参数并重新标定：`ENC_PER_CM`（编码器计数/厘米）、
`WHEEL_BASE_CM`（轮距）、`TURN_SCALE`（原地转系数，实测法见 `文档/烧录与工程搭建指南.md`）、
以及 `LEGS[]` 路线表。
